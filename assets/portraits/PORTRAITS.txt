PORTRAIT SPECIFICATIONS — Escape from the Solid Labyrinth
==========================================================

Purpose
-------
Each statue has a portrait image shown in the inspect panel.
Portraits are currently placeholder (grey rectangle in-game).
This file describes the target spec for real artwork.

Canvas size:   140 × 180 pixels for statue inspection portraits.
               Player portrait is currently 160 × 280 pixels to match the left panel.
Format:        PNG with transparency
Colour space:  sRGB
Style:         Stylised dungeon portrait, slightly desaturated,
               dark background, rim-lit in cold blue/white light.
               Subject is the solidified woman (marble texture overlay acceptable).
               Expression and pose should match the statue's 'pose' field in level data.

File naming:   <statue-id>.png   (matches portraitKey field in StatueEntity)
               Examples: mira.png, petra.png, lyra.png

Placement:     Drop files in this folder. In code, load them in GameScene.preload():
                 this.load.image('<statue-id>', 'assets/portraits/<statue-id>.png')
               Then set portraitKey: '<statue-id>' in the statue's level definition.
