# Portrait Generation Prompts

These are the prompts used for the current portrait batch.

- `player_mint.png` uses the blonde cleric image as the player character base and style reference.
- Statue portraits use the darker petrified adventurer image as the petrification style reference.

## player_mint.png

```text
Use case: stylized-concept
Asset type: game character portrait for a Phaser roguelike UI
Primary request: Create a portrait of the player character using the attached reference image as the character design base and style reference.
Subject: young adult female adventurer cleric, long golden-blonde hair, blue eyes, gentle determined expression, white and gold cleric robe, purple cross-shaped chest ornament, white gloves, gold-trimmed headpiece, holding a staff with a golden orb.
Style/medium: polished anime fantasy RPG character art matching the provided reference image: clean linework, soft cel shading, bright eyes, elegant costume detail, high-quality visual novel portrait style.
Composition/framing: vertical portrait, upper body to mid-thigh, centered, enough margin around the head and shoulders for cropping to 140x180; no text.
Scene/backdrop: dark dungeon portrait backdrop with subtle cool blue rim lighting, not a full environment.
Lighting/mood: cold blue-white dungeon rim light mixed with soft warm character highlights, heroic but vulnerable.
Color palette: white, gold, purple accents, blonde hair, cool dark background.
Constraints: preserve the reference character's blonde hair, blue eyes, white-gold-purple cleric design, staff, and gentle anime style. PNG-style game asset, clean edges, no watermark, no text.
```
